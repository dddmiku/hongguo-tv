# TV 1.3.2 体验优化与验证

2026-11-19，版本 1.3.2 / code 18。本文记录发布前的本地源码优化、独立 QA 设备验证及原签名 ARM64 安装包构建；本轮未对正式应用做覆盖安装。

## 本轮改动

- 播放控制栏：确定键完成暂停或恢复后再设置隐藏计时；隐藏任务执行时复核实际播放、前台及暂停状态。暂停保持显示，恢复后自动收起，未知按键不唤起控制栏；左右键继续保留 TV 原有定位反馈。
- 搜索：成功、业务错误及异常经过同一主线程提交入口，核对请求世代与页面结束状态。旧查询失败不再覆盖新查询成功，页面结束后也不继续修改结果。
- 封面：相同 URL 合并为一个在途任务，排队执行时再次检查缓存，弱引用订阅避免强持有旧视图。同一视图重复绑定去重，旧地址晚到不串图，失败释放任务以允许重试。日志不输出封面完整地址或异常 message。
- 遥控器焦点：首页卡片使用作品 ID 与稳定分区键共同恢复焦点，热播与上新中的重复作品不再因刷新跳到另一行。

## 验证

原实现已通过定向测试复现四类问题：暂停后被旧计时隐藏、恢复播放后不隐藏、旧搜索覆盖新状态、刷新焦点跳行及重复封面下载。8 个视图同时加载同一封面时原实现实际请求 8 次，修复后为 1 次；同一视图重复绑定 20 次也只请求及交付一次。

- 66 项 JVM 测试、4 项独立发布合同测试通过。
- `python -B tools/verify-tv-experience.py --install`：12 项通过，覆盖遥控器控制栏、搜索竞态与生命周期、分区焦点、真实 HTTP 请求数、位图颜色、缓存、换绑与失败重试。
- `python -B tools/verify-player-lifecycle.py --full`：24 项通过，包含实际视频解码、暂停和精确续播、九轮解码返回、历史分页、账号及收藏合同。
- `python -B tools/verify-seasons.py`：5 项受控季播放检查通过；原切季、取消与迟到回调断言保持不变。
- `python -B tools/verify-seasons.py --details`：1 项真实季详情检查通过。
- `python -B tools/verify-seasons.py --live`：1 项真实第 79 集进入下一季首集并重建恢复检查通过。

设备检查合计 43 项，在 MuMu Android 15 ARM64 的独立 `cn.hongguo.tv.qa` 内完成，媒体音量为零。正式包的账号、历史与追剧数据未被这些测试操作。

旧受控季测试在本机多显示器环境串跑时暴露了夹具生命周期问题：debug Activity 缺少正式页的配置处理，且未等待真实前台和旧页面销毁。本轮使夹具配置与正式页一致，并等待真实状态，不强写前台字段；主线程断言回传测试线程，避免测试失败直接杀死进程。收紧后整类及专项接续连跑通过。

MuMu 为应用创建独立显示器，旧默认截图实际截到启动器，不作为本轮播放器视觉通过的证据。主页改用 QA 应用所在物理显示器抓取，截图已检视，位于 `_work/tv-optimize/qa-home.png`。本轮未测实体电视、ARM32、真实短信或 MFA，不把模拟器结果扩展为所有设备通过。
