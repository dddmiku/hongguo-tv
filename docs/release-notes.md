红果客厅 TV 1.3.5 · 2026-11-20 · 系列剧排行榜（ARM64）

本版适用于 64 位 ARM Android TV / 盒子；32 位暂不包含在这次发布中。

- 首页新增「排行」入口，提供系列剧「推荐榜」「新季榜」，并保留漫剧推荐榜、热播榜和新剧榜。
- 榜单直接读取官方排序，展示排名、更新季说明和推荐信息；系列剧按官方入口打开首季，可在详情继续选择其他季，不把最新季集数误当成首季集数。
- 遥控器可在分类、榜单与作品之间上下切换；关闭作品详情、返回首页时恢复对应焦点。
- 切换榜单会清空旧结果并丢弃迟到回复，空榜与加载失败均提供重试。

覆盖安装 hongguo-tv-1.3.5.APK，不要卸载。安装包沿用 cn.hongguo.tv 和原签名，versionCode 21，账号、历史、追剧和设置沿用原数据。

本版通过 93 项 JVM 测试、7 项发布合同测试、9 项排行榜设备验收和 21 项常规体验回归。排行榜验收包含同一次真实接口结果与页面顺序逐项核对、真实系列入口选集、遥控焦点、迟到回复及失败重试。正式包已在 MuMu 从 1.3.4 覆盖升级至 1.3.5，两次均为访客状态，未卸载、未登录或触发云端写入。

本轮没有实体电视、ARM32、真实账号历史与收藏对比、真实短信及真实扫码验证；不同电视的遥控器和硬件解码兼容性仍以实际设备为准。
