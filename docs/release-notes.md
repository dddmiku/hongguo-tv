红果客厅 TV 1.3.1 · 2026-11-12 · 手机播放修复（ARM64）

本版适用于 64 位 ARM Android TV / 盒子；32 位暂不包含在这次发布中。

- 修复取流接口 HTTP 200 空响应：改为国内 SDK JNI 签名，签署实际压缩请求体，并使用官方手机当前播放入口。
- 内容请求带入 TV 自己的设备与登录态，保留原账号和数据；无需依赖电脑版或手机模拟器。
- 下载失败会尝试官方备用 CDN；地址失效后重新取流一次。取消和返回会中断过期准备，下载不完整的文件不会作为可播缓存。
- 正确读取手机按内容类型和视频 ID 分桶的模型，保持同一剧、同一集；保留真实编码与解密信息。
- 沿用全部季、自动续季、遥控器操作、倍速、画质和画面模式；正式包名 cn.hongguo.tv，versionCode 17，原签名不变。

覆盖安装 hongguo-tv-1.3.1.APK，不要卸载。模拟器覆盖安装保留已登录账号、1424 条历史、3 部追剧及播放偏好。

验收：66 项 JVM、4 项发布合同和 34 项静音模拟器检查通过。真实播放原剧第 54、55、70 集；主 CDN 失败后通过真实备用地址下载并解码；季末自动进入下一季并恢复播放器状态。安装后的正式 R8 包第 54 集取流返回 5 条轨道。

本轮没有实体电视测试；ARM32 没有可用国内组件和设备验证环境，不宣称该架构已修复。不同电视硬件解码能力仍以设备实际支持为准。
