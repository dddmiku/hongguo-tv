红果客厅 TV 1.3.4 · 2026-11-20 · 稳定性与更新链路修复（ARM64）

本版适用于 64 位 ARM Android TV / 盒子；32 位暂不包含在这次发布中。

- 更新安装授权返回后只接续一次，取消系统安装后不再立即重开。下载包在安装前核对清单、大小、SHA-256、包名、版本和签名，有效下载可继续重试。
- 修复片库分页遇到重复、无效条目时停在原页的问题。
- 短信验证码票据与手机号绑定，换号、切换登录方式、离开页面或会话变化后不再接收旧请求结果；错误响应缺少数据时仍显示有效提示。
- 扫码登录在保存账号前核对历史和收藏接口，并兼容历史字段别名。
- 修复加密 AVC 视频被误标为 HEVC，限制畸形 MP4 索引解析；诊断信息不再包含媒体解密密钥和上游原始异常。
- 发布流程增加凭据目标域限制、草稿复用和资产摘要验收。
