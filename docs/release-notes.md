红果客厅 TV 1.3.3 · 2026-11-20 · 一键续看与遥控器搜索（ARM64）

本版适用于 64 位 ARM Android TV / 盒子；32 位暂不包含在这次发布中。

- 首页「继续看」按确定直接播放上次的集数和位置。加载可取消，失败可重试。
- 搜索完成后可直接选择首条结果。查询失败可以用原词重试，无结果可以返回改词。
- 长按确定键只切换一次播放状态，左右键仍支持连续定位。
- 首页顶部按返回键可返回电视系统。

覆盖安装 hongguo-tv-1.3.3.APK，不要卸载。安装包沿用 cn.hongguo.tv 和原签名，versionCode 19，账号、历史、追剧和设置沿用原数据。

设备验证使用独立 QA 包和现有 MuMu；本轮没有实体电视或 ARM32 验证，不同电视的遥控器和硬件解码兼容性仍以实际设备为准。
